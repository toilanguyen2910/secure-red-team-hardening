# Security policy

This repository provides instructions and a toy local example; it is not a hosted security service.

If you discover a flaw in these files that could lead users to unsafe behavior, please use GitHub's private **Report a vulnerability** feature on the repository's Security tab if available. If private reporting is unavailable, open an issue without exploit details or sensitive data and ask the maintainer for a private contact channel.

Include the affected file and revision, a concise impact statement, and a minimal synthetic reproduction. Do **not** post real credentials, personal data, or live-target exploit steps.

Do not use this repository as authorization to test third-party systems.
